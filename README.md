# ✈️ TripWise AI

TripWise AI is an AI-powered travel planning application that generates personalized travel itineraries based on the user's travel preferences.

It uses Google Gemini to create customized day-by-day travel plans according to budget, destination, duration, travel style, interests, food preferences, accommodation, mobility needs, and more.

## 🚀 Features

- Personalized AI-generated travel itineraries
- Interactive travel preference form
- Multiple travel styles
- Budget-based planning
- Dietary and cuisine preferences
- Activity and interest selection
- Accommodation preferences
- Walking tolerance and mobility requirements
- Hidden-gem recommendations
- Itinerary refinement using AI
- Downloadable itinerary

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Pydantic
- python-dotenv
